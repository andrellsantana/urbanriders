# Prompts de imagem (ChatGPT)

Um arquivo JSON por imagem. Abra o arquivo, copie **todo** o conteúdo e cole no ChatGPT com:
> Gere a imagem descrita neste JSON, seguindo todas as restrições.

O campo `como_usar_pt` de cada arquivo diz se é preciso uma conversa nova ou a mesma conversa anterior.
O conteúdo do `prompt` está em inglês de propósito: geradores de imagem seguem instruções técnicas com mais precisão em inglês.

| Nº | Conteúdo |
|---|---|
| 01–04 | Andrew-Mike Starr (frontal, lateral, costas, 3/4) |
| 05–08 | Lucienne |
| 09–12 | Russ |
| 13–16 | Mint |
| 17–20 | BMX (lateral, frontal, 3/4, costas) |
| 21–33 | Objetos do cenário |
| 34–37 | Texturas de piso |
| 38–41 | Retratos do HUD |

`_todos_os_prompts.json` reúne todos em um só arquivo.
